## Анализ
По итогам проведённых экспериментов для всех трёх типов входных данных гибридный алгоритм Merge Sort с переключением на Insertion Sort демонстрирует преимущество над классической реализацией Merge Sort

Insertion Sort в данном случае работает ближе к своему худшему случаю, поэтому гибридный алгоритм становится более чувствительным к значению порога. При больших значениях threshold (30 и 50) наблюдаются выраженные выбросы времени, обусловленные квадратичной сложностью сортировки вставками

Для почти отсортированных массивов Insertion Sort работает особенно эффективно, поскольку количество необходимых перестановок минимально. В результате гибридный алгоритм демонстрирует наиболее устойчивое улучшение по времени. Однако выбросы могут появляться на разных размерах массива
