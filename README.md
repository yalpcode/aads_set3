## Анализ
Можно заметить, что для узкого прямоугольника амплитуда колебаний приближённого значения значительно меньше. Это связано с тем, что в широком прямоугольнике большая часть случайных точек попадает в область, где искомой фигуры нет, и поэтому такие точки не дают информации о границах пересечения.

По второму графику видно, что при больших значениях N (>40 000) точность в случае узкого прямоугольника заметно превосходит точность для широкого прямоугольника.

Вывод: для более точного вычисления площади пересечения лучше использовать максимально узкую область, плотно охватывающую границу пересечения, и брать достаточно большое количество случайных точек внутри неё.
